# מעקב יום הניקיון הגדול 2026 · צלול

דשבורד חי המציג את הרשמות ההתנדבות ליום הניקיון הארצי (16/10/2026), נשאב בזמן אמת מטופס ה-Google Sheets.

## תכונות
- כרטיסי סיכום: סה״כ הרשמות (טפסים), סה״כ משתתפים, אתרים פעילים, קבוצות/ארגונים.
- **תקציר מנהלים**: פאי צ'ארט של כלל ההרשמות + טבלת 5 האתרים המובילים (לפי סך משתתפים).
- **טבלת כל האתרים מצפון לדרום** (סדר גיאוגרפי לפי קו רוחב), עם הרשמות ומשתתפים לכל אתר.
- מסנן טווח תאריכי הרשמה דינמי + קיצורי דרך (7/14 ימים אחרונים).
- שורת "עודכן לאחרונה" + כפתור סנכרון + רענון אוטומטי כל 5 דקות.
- ניקוי נתונים אוטומטי בצד הלקוח: הסרת שורות בדיקה (למשל "עדן בדיקה"), ואיחוד הרשמות כפולות (אותו נרשם לאותו אתר, לפי טלפון/מייל).

## מקור הנתונים
הדף שואב CSV חי מהגיליון. כדי שהמשיכה האנונימית תעבוד, הגיליון חייב לאפשר אחת מהשתיים:
1. **הרשאת הורדה לצופים**: שיתוף ← הגדרות (גלגל שיניים) ← לסמן "צופים ומגיבים יכולים לראות אפשרות להוריד, להדפיס ולהעתיק".
2. **פרסום לרשת**: קובץ ← שיתוף ← פרסום באינטרנט ← CSV. להדביק את הכתובת שמתקבלת במשתנה `PUBLISHED_CSV` שבתוך `index.html`.

ניתן גם להעביר מקור זמני בכתובת: `?csv=<URL>`.

python -m http.server 5577
