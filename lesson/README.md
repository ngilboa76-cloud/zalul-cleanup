# החוף שלנו · סביבה לימודית אינטראקטיבית

גרסה דיגיטלית אינטראקטיבית של מערך השיעור "החוף שלנו, מה אנחנו משאירים אחרינו?"
לקראת יום ניקיון החופים הגדול של עמותת "צלול".

מקור: מסמך המערך של הלקוח (Google Doc). הסביבה מחליפה גם את מצגת התלמידים וגם את מדריך המורה.

## הרצה
קובץ אחד, `index.html`. אפשר לפתוח ישירות בדפדפן או להעלות לכל אחסון סטטי.
להרצה מקומית:

```
python -m http.server 5589 --directory C:/zalul-lesson
```

## מצב דוגמית
`index.html?only=1,4,6` מצמצם את הסביבה לשלוש תחנות בלבד, עם באנר "דוגמית" בראש העמוד.
אותו קובץ, בלי עותק שני לתחזק. אפשר לבחור כל צירוף: `?only=4` לתחנה אחת, `?only=1,6,10` וכו'.
כפתורי ה"המשך" שבתוך התחנות קופצים אוטומטית לתחנה המותרת הבאה, כך שאין מבוי סתום.
בלי הפרמטר, כל 11 התחנות פעילות.

## מצב מורה
כפתור "מצב מורה" בכותרת חושף בכל תחנה פאנל כתום עם מדריך המורה:
תזמון החלק, שאלות הנחיה, ותשובות. המצב נשמר ב-localStorage,
כך שאפשר להפעיל אותו על מחשב המורה ולהשאיר אותו כבוי על מחשבי התלמידים.

## מה צריך לאמת לפני שימוש
עמוד יום הניקיון באתר צלול (`zalul.org.il/cleaning-day-2026/`) החזיר 503 בזמן הבנייה,
ולכן פרטי האירוע בכרטיס שבתחנה 10 נלקחו מפרויקט הדשבורד (`C:\zalul-cleanup`):

- **תאריך: 16.10.2026 (יום שישי)** ← לאמת מול העמוד
- שעות הפעילות ← חסר, לא הופיע במקור
- אתר הניקיון של הכיתה ← להוסיף ידנית

לעדכון: `#evDate` ו-`.eventrow` בתוך `index.html`.

## הערות טכניות
- ללא תלויות חיצוניות מלבד Google Fonts. אם אין אינטרנט, יפול חזרה ל-Segoe UI.
- החול בתחנה 4 מצויר ב-canvas, החלקיקים נחשפים דרך CSS mask שנצמד לסמן.
- תמיכה במגע: כל האינטראקציות עובדות ב-pointer events, אין גרירה.
- הדפסה: `window.print()` פורס את כל התחנות כעמודים, בלי אלמנטים אינטראקטיביים.
